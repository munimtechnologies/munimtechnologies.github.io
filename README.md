# munimtechnologies.github.io

The GitHub Pages site of Munim Technologies: browser tools by MV2 of Munim, Inc.

- `inclusive-criteria/`: the inclusive eligibility check, a copy of `web/check.html` from
  [trial-exclusion-census](https://github.com/munimtechnologies/trial-exclusion-census) (rules of
  its v0.5.0 release). It runs entirely in the page.
- `math-annotation-consistency/`: a research write-up with its code and results. Do the worked
  solutions in GSM8K, MathQA and AQuA-RAT add up? One exact-arithmetic check across all three,
  with predictions filed in advance and graded as written.
